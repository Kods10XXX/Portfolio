Deep Learning · Computer Vision

Reconstruction 3D parallèle — Neural Radiance Fields

Projet académique · Calcul Parallèle et Distribué · Master 1

Système complet qui reconstruit la géométrie 3D d'un objet à partir d'un ensemble de photos, puis génère des vues inédites sous n'importe quel angle. L'objectif : appliquer concrètement le calcul parallèle (GPU CUDA et multiprocessing CPU) à un vrai pipeline de Deep Learning, et mesurer le gain réel — jusqu'à un dashboard live suivant loss, PSNR et speedup itération par itération.

111×Speedup GPU
1.75×Speedup CPU
~25 dBPSNR / 5k iter.
32.7 ms/ itération (FP16)

Points clés de l'implémentation :

  • MLP de 8 couches (256 neurones) avec skip connection (1 114 625 paramètres) et positional encoding (L=10).
  • Volume rendering (intégration Beer-Lambert) entièrement vectorisé en PyTorch — 65 536 points évalués en parallèle par itération.
  • Entraînement en précision mixte (FP16) avec Adam + ExponentialLR + GradScaler.
  • Extraction parallèle des frames vidéo via multiprocessing.Pool, rendu final exporté en vidéo 360°.

TaskManager — orchestration Docker Compose & Swarm

Projet académique · Systèmes distribués & conteneurisation

Application web à trois services — frontend Nginx, API Node.js/Express et PostgreSQL — entièrement conteneurisée, déployée d'abord avec Docker Compose puis mise à l'échelle avec Docker Swarm (secrets, rolling updates, rollback).

3Services conteneurisés
2Modes : Compose & Swarm
10×Retry PostgreSQL

Points clés de l'implémentation :

  • Reverse proxy Nginx (/api/ → backend) et frontend type SPA sans rechargement complet.
  • Healthchecks sur les deux orchestrateurs ; backend exécuté sous utilisateur non-root.
  • Gestion du mot de passe DB via variables d'environnement (Compose) ou Docker Secret (Swarm).
  • Mise à l'échelle horizontale et mises à jour progressives avec rollback en cas d'échec.
